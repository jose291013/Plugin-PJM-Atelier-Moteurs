# Product Excel import / export

Screen `/site/{domain}/Products/ProductImportExport` (button Import/Export on the product list).
- Export: `#includeDeleted`, `#btnExport` « Exporter maintenant ». Empty template: « Télécharger l'Excel à remplir » (`/Products/ExportProductsTemplate`).
- Import: form to `/Products/ImportProducts`, `input[type=file]#file`, **`#replaceItems` « Supprimer les produits ne figurant pas dans le fichier Excel » — never check it**, `#btnImport` « Importer maintenant ».
- Matching: column **Product Id** = update that product; empty Product Id = **create**. A file with only the rows to change touches only those products.
- The user receives a report « Product Import Result for {site} » (Errors, Added, Failed, Ignored, Removed, Updated, Total + per-row errors). Claude cannot see it: ask the user for it, then check the list.
- **Upload**: Claude cannot drop the file. Write it to the user's connected work folder; the user drops it and clicks import.

## File format (sheet « Sheet0 », 137 columns, one row per product)
Product Id, Product Name, Url Name, Active · pricing couples n = 1..5: `Site Group price n`, `Pricing Engine price n`, `MIS Product ID price n`, Template No., Item No., Quantities, Per Piece weight · kits (Kit Role, Weight Per Kit, Kit Option Per Kit Fee, Kit Options Prompt, Kit Options Setup Fee, Kit Pricing Method, KitComponents) · Suggested Product 1..5 · Open Frame (3) · Featured Product, Enable Quick View, Part Number, Public Part Num, Teaser Price, Display image on detail page, Display Shipping Estimator, Allow user to print estimate, Print estimate additional information, "I Accept" Requirement, Acceptance Text, Allow Edit Product Name on Ordering · stock / shipping (Inventory Stock to Use, Back Order Allowed, Hide Product…, In/Out of stock ship days, Will ship separately, Digitally Deliver File, Ship From Location) · tax (Override Tax, Apply Tax Override to Shipping, Tax ID) · Order Status Workflow, Integration ID, Product's Physical Location Notes, Outsource to Vendor, Show Price Without Markup to Vendor, Vendor Instructions, Folding/Finishing/Binding/Packaging JDF · eDocBuilder (Template, Alternate Button Text, Show eDoc preview in cart, Create eDoc Proof PDF, Instructions, Approval Text) · **Long Description**, **Short Description** (HTML) · Q1–Q5 Min/Max/Decimal Places/Allow Arbitrary · Minimum Price, Show Per Piece Price, VDP/Asset/Upload Sets Quantity · Custom Order Form · **Site Group 1..5** · dates (Last modified, Creation, Modification, Deletion) · Upload Fields (Required, Show Scaled Preview, Dimensions XML, Current Upload Fields XML) · **Primary Image URL** · Price per piece decimal places, Tax ID, Ship From Location, Pricing comparison, Use PDF2Press Workflow Proofing.
Formats: booleans `True`/`False`; decimals with comma (`0,0000`); dates `YYYY-MM-DD hh:mm:ss`. A file rewritten with openpyxl (rows removed) is accepted.
PJM product: `Site Group price 1` = « Tou le monde », `Pricing Engine price 1` = « APJM », `MIS Product ID price 1` = integration Id.

## Pitfalls (tested 18/10/2026)
- **Visibility groups truncated to 5**: export has only `Site Group 1..5`. A product visible to 6 groups loses the 6th on import (« Tou le monde » was unchecked). Before importing, compare each product's checked groups in the admin; if > 5, don't import it by Excel or re-check its groups right after. Same caution for `price 1..5` and `Suggested Product 1..5`.
- **Image URL**: the export gives `…/xxx_original.png?stamp=…`; with `?stamp=` the row fails (« Error to import product primary image… public url »). Remove the query string. `https://admin.{region}.v6.pressero.com/files/subscribers/…` URLs are public.
- **Creation**: empty Product Id and the 4 date columns; new unique Url Name.
- Custom Order Form not applied on creation when the form is a file-upload form (incompatible with product pages anyway).
- After any import: count products in the list, open each imported product (groups, pricing couple, description), test the price on the storefront.
